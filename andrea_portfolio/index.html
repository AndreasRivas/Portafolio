03 Asistente Visual RápidoA prototype concept for obstacle detection with fast sound and voice alerts. +
ACCESSIBILITYWEB DEVELOPMENTASSISTIVE TECHNOLOGY

Asistente Visual Rápido is an accessibility-focused project designed to support people with visual impairments through obstacle-detection concepts and audio feedback. Its interface includes controls for alert repetition, voice speed, and detection sensitivity.

Project purpose

Explore how technology and sound-based feedback can help make navigation more accessible.

Current status

The published demo currently displays a local-model loading notice. The detection model needs to be served with the project files for the full experience to run.

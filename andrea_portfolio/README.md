# Andrea — Student Portfolio

A responsive, English-language student portfolio with sections for About, Projects, Languages, Skills, Certifications, and Contact.

## Preview locally
Open `index.html` in a browser.

## Personalize before publishing
- Replace `assets/profile-placeholder.svg` with your own portrait.
- In the Projects section, edit Project Two and Project Three with your project names, summaries, full descriptions, contributions, and technologies.
- Replace each GitHub link with the direct URL of the corresponding repository.
- Confirm the English proficiency label and certification years/details before publishing.
- Add your LinkedIn profile URL when available.

## Publish with GitHub Pages
1. Create a **public** repository on GitHub.
2. Upload the contents of this folder (not the ZIP file itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and copy the website URL.

The contact email and GitHub profile link are already included. No phone number or home address is published.
